## 계산 관련 추가 메모 (반올림)

- 매입금액·평가금액은 각 보유 종목의 원화 환산 금액을 `BigDecimal`로 더한 뒤, **최종 합계에서만** 원 단위 절사(`RoundingMode.DOWN`)합니다. 중간에 종목별로 미리 절사하면 오차가 누적될 수 있어 피했습니다.
- 수익금(`profit`)은 절사된 평가금액에서 절사된 매입금액을 뺀 값입니다. 그래야 화면에 보이는 세 숫자(매입금액, 평가금액, 수익금)의 뺄셈이 항상 맞습니다.
- 수익률은 `수익금 / 매입금액 × 100`을 소수 둘째 자리에서 반올림(HALF_UP)합니다.
