## 계산 관련 메모 (반올림)

- 매입금액과 평가금액은 보유 종목별 원화 환산 금액을 `BigDecimal`로 더한 뒤, **최종 합계에서만** 원 단위 미만을 버립니다(`RoundingMode.DOWN`). 종목별로 먼저 버리면 오차가 쌓일 수 있기 때문입니다.
- 수익금(`profit`)은 버림 처리한 평가금액에서 버림 처리한 매입금액을 뺀 값입니다. 이렇게 해야 화면에 보이는 매입금액, 평가금액, 수익금의 계산이 항상 맞습니다.
- 수익률은 `수익금 / 매입금액 × 100`을 소수 둘째 자리까지 반올림(HALF_UP)합니다.
