## 추가한 필드

| 위치 | 필드 | 설명 |
|---|---|---|
| `GET /api/v1/portfolios/{id}`와 목록 조회의 `summary` | `priceStale` (boolean, 정상일 때는 생략) | 시세 서버 장애로 마지막으로 가져온 시세를 계속 사용할 때만 `true`로 응답합니다. 정상일 때는 응답에 이 필드가 없습니다. (가정 문서 4번 참고) |

## 상태 코드 요약 (명세와 동일, 참고용)

| 상황 | 코드 | 본문 |
|---|---|---|
| 상품 조회 성공 | 200 | |
| 포트폴리오 생성 | 201 | |
| 포트폴리오 조회, 수정 | 200 | |
