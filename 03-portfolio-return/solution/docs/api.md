# API 문서 (계약 밖에 추가한 것)

고정된 경로와 필드는 가이드 5장을 그대로 따릅니다. 이 문서는 **추가로 넣은 것**만 적습니다.

## 추가한 필드

| 위치 | 필드 | 설명 |
|---|---|---|
| `GET /api/v1/portfolios/{id}`, 목록의 `summary` | `priceStale` (boolean, 문제가 없으면 생략) | 시세 서버 장애로 마지막 성공 시세를 계속 쓰고 있을 때만 `true`로 나타납니다. 정상일 때는 필드 자체가 응답에 없습니다 (가정 문서 4번 참고) |

## 추가한 API

없습니다. 계약에 정의된 API만 구현했습니다.

## 상태 코드 요약 (계약 그대로, 참고용)

| 상황 | 코드 | 본문 |
|---|---|---|
| 상품 조회 성공 | 200 | |
| 포트폴리오 생성 | 201 | |
| 포트폴리오 조회·수정 | 200 | |
| 포트폴리오 삭제 | 204 | |
| 입력 오류 | 400 | `INVALID_REQUEST` |
| 존재하지 않는 상품 코드 | 400 | `UNKNOWN_PRODUCT` |
| 없는 포트폴리오 | 404 | `PORTFOLIO_NOT_FOUND` |
| 시세가 아직 없음(생성·수정) | 503 | `PRICE_NOT_READY` |
