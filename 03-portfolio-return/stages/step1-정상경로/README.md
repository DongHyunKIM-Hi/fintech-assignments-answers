# 1단계 — 정상 경로

과제 3(가상 포트폴리오 수익률 서비스) 정답 코드를 세 단계로 나눈 것 중 첫 번째입니다.
전체 설명은 `../README.md`를 보세요.

## 실행

```bash
docker run -p 9091:9091 ghcr.io/donghyunkim-hi/portfolio-price-server:1.2.0   # 가상 시세 서버
./gradlew bootRun                                                            # 포트 8080
```

시세 서버 주소는 환경변수 `PRICE_BASE_URL`로 바꿉니다.

## 이 단계에서 만드는 것

- `data/products.csv`를 읽어 저장하고, `GET /api/v1/products`로 전부 돌려줍니다.
- 포트폴리오 생성, 조회, 목록, 수정, 삭제가 동작합니다.
- 시세는 요청이 올 때마다 시세 서버에서 받아 와 평가금액을 계산합니다.

## 일부러 하지 않는 것

| 하지 않는 것 | 그래서 생기는 일 | 해결 단계 |
|---|---|---|
| CSV 정리 (중복 코드, 통화 6종, 날짜 3형식, 빈 값) | 지저분한 값이 응답에 그대로 나옵니다 | 2단계 |
| 검색, 정렬, 필터, 페이지 | 상품 130행을 한 번에 전부 돌려줍니다 | 2단계 |
| 입력 검증과 에러 응답 | 잘못된 요청이 500으로 나갑니다 | 2단계 |
| 매입가 고정 | 수익률이 늘 0입니다 | 2단계 |
| 환율 환산, 금액 버림, 수익률 반올림 | 달러 상품 금액이 틀립니다 | 2단계 |
| 30초 주기 갱신, 토큰 재사용, 장애 대비 | 요청마다 토큰을 새로 받고, 시세 서버가 멈추면 GET도 500입니다 | 3단계 |

코드에서 덜어낸 자리에는 모두 한국어 주석으로 표시해 두었습니다.
