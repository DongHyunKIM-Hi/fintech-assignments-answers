# 과제 4. 쿠폰 사용과 회의실 예약: 평가 기준표

> 튜터용 문서 · **최종본 v1.2** (2026-10-08)
> 워밍업 과제라 기준표도 짧습니다. 튜터가 수강생 제출물을 직접 실행하고 읽어서 채점합니다. 함께 쓰는 자료: 같은 폴더의 `solution/`(정답 서버)

## 1. 배점 요약

| 영역 | 배점 | 판정 방법 |
|---|---|---|
| A. 정확성 | 70 | 튜터가 직접 실행 (curl 또는 IntelliJ HTTP Client로 아래 시나리오 재현) |
| B. 코드 품질 | 30 | 코드와 README를 읽고 판정 |

### 평가 순서
1. 수강생 서버를 `./gradlew bootRun`으로 8080에서 기동한다.
2. 2장의 시나리오를 실행한다. 수강생 저장소의 `requests.http`에 순차 요청 예시와 동시 요청용 셸 스크립트 예시가 있다.
3. 코드와 README를 읽고 3장(B)을 판정한다.
4. 4장의 치명 오류를 확인한다.

> **동시 요청 보내기 (A2~A4, A7, A9)**: 셸에서 `for i in $(seq 1 5); do curl -s -X POST ... & done; wait`처럼 `&`로 동시에 보낸 뒤 응답 코드 개수와 조회 결과를 확인합니다.
>
> **정답 서버와 비교하기**: 판단이 애매하면 `solution/`을 띄워 같은 요청을 보내 보면 기대 동작을 바로 확인할 수 있습니다.
