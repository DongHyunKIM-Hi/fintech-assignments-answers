# 1단계 — 정상 경로

해설 영상용 단계별 코드의 첫 단계입니다. 단계 구분과 실측 결과는 [`../README.md`](../README.md)에 있습니다.

- **만드는 것**: 메뉴 목록 조회, 포인트 충전·조회, 주문과 결제, 인기 메뉴 조회. 네 API가 MySQL로 동작합니다.
- **일부러 하지 않는 것**: 입력 검증, 에러 응답 형식, 잔액 확인, 트랜잭션, 데이터 수집 플랫폼 전송,
  인기 메뉴의 7일 범위, 동시성 제어. 각 자리에 왜 그런지와 몇 단계에서 채우는지를 주석으로 적어 두었습니다.

```bash
docker compose up -d --wait   # MySQL 8.4 (3306), Redis 7.4 (6379)
./gradlew bootRun             # 8080
```

- 1단계는 Redis를 쓰지 않습니다(3단계에서 분산 락과 인기 메뉴 집계에 씁니다).
- `schema.sql`, `data.sql`, `build.gradle`, 패키지 구조는 3단계(`../../solution/`)와 같습니다.
- 테스트 코드는 없습니다. 테스트는 3단계에서 다룹니다.
